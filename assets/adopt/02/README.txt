This folder holds the photo for one elder card on the Adopt page.

Required file:
  photo.jpg   — square-ish photo works best, min. 800x800px recommended

This elder's name/age/city/story/status/sponsorship info lives in
/data/elders.json (the entry with "photo": "assets/adopt/02/photo.jpg").
